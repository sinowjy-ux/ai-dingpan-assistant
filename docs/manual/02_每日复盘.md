# 三、每日复盘

点 **生成 / 更新今日复盘**，约 1 分钟生成。程序开着时，交易日 9:00 自动生成盘前版、15:35 以后自动生成收盘版。右上角下拉框可查看历史复盘（只要当天生成过，就永久保存在数据库里）。

> 复盘只能生成“最近一个交易日”的：外围快照、资金流向等数据接口不提供历史回溯。

复盘分 7 部分，顺序和 A 股开盘前后关注的顺序一致。

## 3.1 外围市场

- **隔夜美股**：道琼斯、纳斯达克、标普500、费城半导体 ETF、纳斯达克中国金龙指数，以及英伟达、苹果、特斯拉、阿里巴巴、拼多多；标题里写明是美国哪一天的收盘。
- **港股 · 亚太 · A50**：恒生指数、恒生科技、日经225、韩国 KOSPI、富时 A50 期货。
- **商品 · 汇率**：纽约原油、黄金、白银、美铜、美元指数、离岸人民币。

## 3.2 外围对 A 股的影响

每个外围因素对应一组 A 股板块，先给出**预期方向**，再用当天这些板块的**实际平均涨跌**来验证：

| 外围因素 | 对应 A 股方向 | 视为“明显”的幅度 |
|---|---|---|
| 费城半导体 | 半导体、芯片、存储、光刻、算力、光模块等科技链 | ±2% |
| 英伟达 | AI 算力链（算力、CPO、光模块、液冷、服务器、PCB） | ±3% |
| 纳斯达克 | 成长股情绪（软件、计算机、通信设备、电子） | ±1% |
| 中概金龙指数 | 互联网、传媒、游戏、电商 | ±1.5% |
| 特斯拉 | 特斯拉链、汽车零部件、机器人 | ±3% |
| 苹果 | 消费电子、果链 | ±2% |
| 原油 | 石油、油气、油服、炼化 | ±2% |
| 黄金 | 贵金属、黄金 | ±1.5% |
| 美铜 | 工业金属、铜、有色 | ±1.5% |
| 离岸人民币 | 外资 / 汇率（人民币贬值通常对应外资流出压力） | ±0.3% |

- **兑现**：相关板块平均涨跌与预期同向且幅度 ≥ 0.5%；
- **背离**：方向相反且幅度 ≥ 0.5%（说明 A 股有自己的逻辑）；
- **未明显体现**：幅度不到 0.5%。

## 3.3 A 股大盘

- **指数**：上证、深证成指、创业板指、科创50、沪深300、中证500、中证1000、北证50。
- **两市成交额**：沪市 + 深市，与前一日比放量 / 缩量多少，与 5 日均量比，附近 5 日柱状图。
- **涨跌分布**：上涨 / 平盘 / 下跌家数，按涨跌幅分 9 档的柱状图，涨跌幅中位数（比平均更能代表“普通股票”的表现）。
- **涨停 · 跌停 · 炸板**：炸板 = 盘中摸到涨停但收盘没封住；炸板率 = 炸板 ÷（涨停 + 炸板），越高说明追涨资金亏钱越多。
- **连板梯队**：几连板各有哪些股票，最高几连板（市场短线情绪的高度）。

统计范围：沪深 A 股，不含北交所和 ST。

## 3.4 资金流向

“主力净流入”= 超大单 + 大单的买入减卖出（腾讯行情口径）。

- **全市场主力净流入**：今日、近 5 日累计、近 20 日累计；
- **行业**（申万一级 31 个）净流入前 10、净流出前 10；
- **概念板块**净流入前 10、净流出前 10。

## 3.5 板块涨跌与主要原因

列出申万二级行业、概念板块的领涨和领跌各 5 个。每个板块的“原因”由以下几项拼成，每一项都有数据出处：

1. 主力资金净流入 / 流出多少，在全部板块里排第几；
2. 板块内上涨家数 / 总家数（普涨还是个股行情）；
3. 领涨股（或领跌板块里跌得最多的成分股）；
4. 外围联动：如果这个板块属于第 3.2 节里有明显波动的外围因素，标出来；
5. 当天相关快讯：从东方财富 7×24 快讯里按板块名称和成分股名称匹配，最多 3 条，点标题可打开原文。

> 原因是“相关性线索”，不是因果结论。快讯匹配按关键词，偶尔会匹配到关系不大的消息，请自行判断。

## 3.6 选股比对

- 今天主力选股、盯盘各存了多少条，其中“已验证 / 命中”多少条；
- **上一个交易日**选出的股票今天的表现：按方法列出条数、T+1 平均、胜率、超额、跑赢大盘的比例。

## 3.7 汇总与明日要点

把以上各部分的关键数字拼成一段摘要（每个数字都能在上面找到出处），再根据规则给出“明日要点”，例如：

- 沪深300 在 20 日线下：轻仓，突破类信号只观察；
- 下跌家数远多于上涨家数：普跌行情，先看能否止跌；
- 炸板率 ≥ 35%：短线追涨亏钱效应明显；
- 明显缩量下跌 / 明显放量：提示关注的方向；
- 外围因素已兑现：次日继续看隔夜同一指标。

这些要点是机械规则，不是投资建议。
