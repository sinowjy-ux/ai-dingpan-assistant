# 七、本地数据库与数据存放

所有数据只保存在你自己的电脑上，不上传任何服务器。

## 7.1 存放位置

| | Mac 版 | Windows 版 |
|---|---|---|
| 程序与数据目录 | `~/Library/Application Support/AI盯盘助手/app/` | 解压目录下的 `app\` |
| 数据库 | `data/journal.db` | `app\data\journal.db` |
| 历史日 K | `screener/cache/klines/`（每只股票一个 CSV） | 同左 |
| 盯盘分时 | `monitor/cache/` | 同左 |
| 日志 | `~/Library/Logs/AI盯盘助手.log` | — |

统计页右上角（Mac）有“在访达中显示数据库”按钮。

## 7.2 数据库里有什么

数据库是一个 SQLite 文件，可以用免费的 **DB Browser for SQLite** 打开查看或导出 Excel。

| 表 | 内容 |
|---|---|
| picks | 每天的主力选股结果、AI 盯盘信号（日期、时间、代码、名称、方法、等级 / 评分、信号价、止损、是否验证、触发理由、详细条件） |
| perf | 每条记录之后的表现：T+1 / T+3 / T+5 / T+10、同期大盘、5 日最高 / 最低、是否破止损 |
| reviews | 每日复盘全文和摘要 |
| favorites | 收藏（选股、盯盘、个股研判） |
| analyses | 个股研判记录：时间、代码、名称、输入参数、评级、综合分、买入区间、止损、目标价、风险回报比、结论 |
| runs | 每次保存的记录（来源、条数、时间） |

## 7.3 备份与迁移

关闭程序后，复制 `journal.db` 即可备份；放回原位置即可恢复。换电脑时，把整个数据目录复制过去，可以省掉重新下载历史数据的时间。

## 7.4 清理

在统计页“数据管理 · 删除”里按天 / 周 / 月 / 年或“某天之前”删除，详见第二章。行情缓存可以直接删除 `screener/cache/klines/` 和 `monitor/cache/`，下次使用时会重新下载。
