# 五、主力选股

主力选股把 8 种常见的 **K 线形态** 和 **筹码形态** 写成明确的规则，每天扫描全部 A 股（不含北交所、ST），并用 **2025 年至今的全市场回测** 检验每种方法是否真的跑赢大盘。

## 5.1 怎么用

1. 点 **更新行情并扫描**（约 1–2 分钟；A 股交易时段每 10 分钟自动更新一次，可关闭）。每次扫描结果自动存入数据库。
2. 顶部显示**数据日期、行情时间、扫描时间**（都是北京时间）和数据是否为今天的。
3. 方法按钮可筛选；“仅最新交易日 / 近 3 个交易日”；最低评分；“只看回测验证有效”。
4. 点一行看详情：形态依据、建仓规则、止损、目标位、风险提示；点 ☆ 收藏。
5. **假跌破观察**：已出现“假跌破”、正在等待突破上颈线的股票名单（见 5.3）。

## 5.2 名词解释

| 名词 | 含义 |
|---|---|
| 筹码分布 | 按每天的成交量和换手率，估算市场上的持股成本分布在哪些价位（移动成本模型，与同花顺口径核对过，误差 < 0.5 个百分点） |
| 筹码峰 | 筹码最集中的价位，即持股成本最多的位置 |
| 单峰 / 集中度 | 筹码只有一个明显的峰叫单峰；90% / 70% 集中度 =（90% 或 70% 筹码所在价格区间的上沿 − 下沿）÷（上沿 + 下沿），数字越小越集中 |
| 颈线 | 前期低点（用 K 线实体最低价，不看下影线）形成的水平线 |
| 上颈线 | 前低之后那次反弹的最高点（K 线实体） |
| 等幅 | 上颈线 − 最低价，用来计算分档目标位 |
| 大盘在 20 日线上 | 沪深300 ETF 收盘价在 20 日均线上方，是多数方法生效的前提 |
| 超额 | 每笔交易收益 − 同一持有期全市场等权平均收益，用来剔除“大盘涨了所以赚钱” |

## 5.3 八种方法的名称与含义

| 方法 | 名称的含义 | 判定规则 | 买点 / 卖点（回测口径） | 回测结论 |
|---|---|---|---|---|
| **筹码峰突破** | 筹码高度集中在一个价位（单峰），放量收盘突破这个峰位，说明集中持股的资金开始拉升 | 突破前筹码单峰，90% 与 70% 集中度都 < 10%（相对集中放宽到 15%）；当天成交量 ≥ 前一日 2 倍；收盘高于筹码峰；处于低位（近 250 日区间 75% 以下，且不高于 120 日最低价的 1.35 倍） | 等回踩到信号日收盘价附近买入；连板后打开涨停即卖；跌破止损卖 | 有效（需大盘在 20 日线上） |
| **箱体突破** | 股价在一个箱体里多次冲到同一上沿都没突破，之后终于收盘突破 | 20 日（小周期）或 60 日（大周期）横盘，K 线实体高点至少 3 次冲到同一上沿未破，区间振幅不超过 25% / 35%；第 4 次及以后收盘突破上沿 | 突破当天买；跌破上沿 3% 止损；盈利 10% 后回到成本出局；最多持有 20 天 | 有效（需大盘在 20 日线上） |
| **假跌破回升** | 先跌破前低（看似破位，其实是假跌破），随后翻回前低之上，再突破反弹高点，确认底部 | 自前高回撤 ≥ 28%；前低之后至少反弹 12%（底部来回震荡过）；跌破前低后收盘翻回 → 进入**观察名单**；之后 60 个交易日内收盘突破上颈线、期间没有再跌破颈线 → 出买入信号 | 突破上颈线当天收盘买；收盘跌回上颈线下方 5% 止损；按等幅分档，突破某一档后又跌破即止盈 | 有效（需大盘在 20 日线上）。翻回颈线当天就买两年都没有超额，所以买点放在突破上颈线 |
| **底部三K反转** | 通用 K 线形态“早晨之星”（Morning Star）：大阴线 → 跳空小 K 线 → 大阳线，出现在最低位，表示空头衰竭 | 中大阴线（跌 ≥ 3%）；次日跳空低开的小阴 / 小阳 / 十字星（实体 ≤ 1.5%）；再接中大阳线（涨 ≥ 3%），收复阴线实体一半以上；位于近 60 日最低位 | 阳线当天买；星线最低点下方止损；盈利 10% 后回到成本出局；最多 20 天 | 不稳定（2025 有效、2026 无效） |
| **涨停换筹** | 涨停当天筹码在涨停价附近大量换手，出现一根全新的最长筹码线，说明有新资金在高位集中承接 | 当天涨停（一字、T 字、普通涨停都算）；出现全新的、最长的筹码线，位置在涨停价附近；成交量 ≥ 前 5 日均量 1.25 倍 | 次日高开不超过 5% 买入；哪天不涨停哪天卖，最多 3–4 天；跌破 20 日线或两天不涨止损 | 不稳定 |
| **三波下跌反弹** | 跌破平台后连续三波下跌（三个依次更低的低点），止跌后博一段小反弹 | 三波下跌；十字星或小实体止跌，位于近 60 日最低附近；次日阳线（涨 ≥ 2%） | 阳线当天买；+10% 止盈；跌破最低点止损；最多 10 天 | 不稳定（实验性） |
| **二次涨停** | 涨停 → 洗盘回调 → 再次涨停，第二次涨停说明资金去而复返 | 两个涨停相隔 1–40 个交易日；第二板收盘不高于第一板 10%（创业板 / 科创板 20%）；此前出现过筹码峰突破，或当天筹码单峰密集 | 次日高开不超过 5% 买入；不涨停即卖，持股 ≤ 5 天；跌破两根涨停 K 线最低价止损 | 不稳定 |
| **看涨吞没** | 通用 K 线形态“阳包阴”（Bullish Engulfing）：大阳线实体完全包住前一天的大阴线实体 | 阴线跌 ≥ 4%、次日阳线涨 ≥ 4%，阳线实体包住阴线实体；阳线成交量大于阴线；筹码单峰密集或此前出现过筹码峰突破 | 阳线尾盘买；两根 K 线实体最低点止损 | 无效 |

所有选股结果还会叠加通用风控提示：上方仍有明显套牢筹码峰（获利盘偏低）时扣分并提示“上方套牢盘压力大”；近两周缩量阴跌扣分；亏损股（市盈率为负）提示业绩风险。

## 5.4 “已验证”与“未通过样本外检验”是什么意思

回测把 2025 年和 2026 年分开看：**只有两年都跑赢大盘的方法 / 组合才判为“有效”**。如果一年跑赢、一年跑输，判为“不稳定”；两年都没跑赢判为“无效”。

- 列表里带 **✓ 已验证** 的信号：属于“有效”的方法，并且当天满足它的前提（例如大盘在 20 日线上）；
- 写着“该方法未通过样本外检验，仅供参考”的信号：方法本身不稳定或无效，只作观察；
- 写着“大盘在 20 日线下，该方法此时历史上跑输大盘”：方法有效，但今天的大盘环境不满足。

回测是历史，真正的检验是之后的走势：统计页的“方法实盘跟踪”会持续记录每种方法的真实表现。

## 5.5 假跌破观察名单

| 列 | 含义 |
|---|---|
| 翻回日 | 跌破前低后收盘翻回颈线的那一天 |
| 颈线 / 上颈线 | 见 5.2 |
| 距上颈线 | 现价还要涨多少才突破上颈线（≤ 3% 金色高亮） |
| 已等 / 剩余 | 翻回后已经过了几天，离 60 天期限还剩几天 |
| 回撤 | 底部相对前高跌了多少 |

收盘突破上颈线那天，这只股票会以“假跌破回升”出现在选股结果里；如果期间收盘跌破颈线或超过 60 天，就移出名单。
