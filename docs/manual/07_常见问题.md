# 八、常见问题

**Q：Mac 提示“无法打开，因为无法验证开发者”或“已损坏”。**
A：这是个人开源软件没有付费签名导致的。到“系统设置 → 隐私与安全性”点“仍要打开”；或在终端执行 `xattr -dr com.apple.quarantine /Applications/AI盯盘助手.app` 后再打开。

**Q：Windows 提示“Windows 已保护你的电脑”。**
A：点“更多信息 → 仍要运行”。安装包里只有 Python 官方嵌入版、numpy 和本程序的源代码，可以自行查看；下载后也可以核对 SHA256 校验值。

**Q：Windows 双击启动后没有窗口。**
A：等几秒再双击一次；或双击“用浏览器打开（备用）”；或在浏览器访问 `http://127.0.0.1:8765/dashboard.html`。如果 8765 端口被别的程序占用，请先关闭那个程序。

**Q：统计页一直显示“首次使用：正在下载…”。**
A：首次下载 5000 只股票的 5 年日 K 需要 10–25 分钟。如果显示“当前没有在下载”，到主力选股页点“更新行情并扫描”。网络不稳定时少数股票会下载失败，不影响使用，下次更新会自动补齐。

**Q：数据和同花顺 / 东方财富有一点不一样。**
A：行情来自公开接口，复权方式、主力资金口径（超大单 / 大单的划分）各家不同，存在小幅差异是正常的。

**Q：复盘里的“原因”准确吗？**
A：原因是根据资金、涨跌家数、龙头股、外围联动和快讯关键词自动拼出来的“线索”，不是因果结论，需要自己判断。

**Q：为什么很多信号写着“未通过样本外检验”？**
A：说明这种方法在回测的两个年份里表现不一致或都没跑赢大盘，只供观察。见第五章 5.4。

**Q：可以用它自动下单吗？**
A：不可以，本软件不连接任何券商，不下单，只做研究和复盘。

**Q：怎么看当前版本？**
A：Mac 版在统计页标题“数据驾驶舱”旁边，Windows 版在左上角“AI 盯盘助手”后面，形如 `v1.0.0-beta.1 公测版`。每个版本改了什么见“更新日志”。

**Q：怎么反馈问题、一起改进？**
A：在发布视频的评论区留言或私信作者。反馈时请按安装包里的“反馈模板.txt”写明**软件版本号**、系统版本、哪个页面、出现了什么提示（Mac 可附日志 `~/Library/Logs/AI盯盘助手.log`）。
