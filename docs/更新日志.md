# 更新日志

版本号规则：`主版本.次版本.修订号-阶段.序号`，例如 `1.0.0-beta.1`。
- **beta.N**：公测版，每收集一轮反馈、修一批问题就加 1（beta.1 → beta.2 …）；
- **修订号**（1.0.x）：正式版里只修问题、不改功能；
- **次版本**（1.x.0）：加功能或改方法规则；
- 构建号（如 20261125）是打包日期，同一版本重新打包时会变。

反馈问题时请写明版本号（App 统计页标题旁、网页版导航栏都能看到）。

## v1.0.0-beta.1（2026-11-25，公测第 1 版）

首个公开测试版。
- 统计（数据驾驶舱）：本地数据库总览、按天查询、方法实盘跟踪（样本外检验）、收藏、按天 / 周 / 月 / 年删除
- 每日复盘：外围市场 → 外围对 A 股的影响（自动验证）→ 成交额与涨跌停 → 资金流向 → 板块涨跌原因 → 选股比对 → 汇总与明日要点
- AI 盯盘：A 股 / 美股，前 1500 / 前 3000 / 全市场；6 套日内策略 + 纪律分；回放与实时盯盘；命中榜与系统通知
- 主力选股：8 种 K 线与筹码形态，两年全市场回测；“假跌破回升”买点改为突破上颈线；假跌破观察名单
- 个股研判：A股 / 港股 / 美股，买卖区间、止损、仓位测算；每次研判自动记录，可收藏
- 界面颜色：深色 / 浅色 / 跟随系统；Mac 版与 Windows 版界面和功能一致
- Mac 通用版（Apple 芯片 + Intel）与 Windows 绿色版，均自带 Python
- 国内网络自动改用腾讯行情数据；首次使用自动下载 5 年历史数据，可断点续传
